# Інтерактивний мокап Pixel 8

Запустіть у цій папці:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Відкрийте `http://127.0.0.1:8765/`. Інтернет для роботи не потрібен.

Перетягування обертає телефон, коліщатко масштабує, перетягування правою кнопкою переміщує. Завантажте PNG, JPEG або WebP і виберіть вписування чи обрізання. Експорт PNG має вибрані пропорції та роздільність; скриншот не передається на сервер і не зберігається між сеансами.

Модель — незалежна інтерпретація Pixel 8, не офіційна модель Google. Габарити корпусу 70,8 × 150,5 × 8,9 мм, пропорції екрана 20:9 — за [специфікацією Google](https://support.google.com/pixelphone/answer/7158570). Радіуси, ширина рамок, камера, задня панель і кнопки приблизні. Фронтальна текстура — наданий згенерований `pixel8-generated.png`; задня панель, грані та об'єктиви створені геометрією. Екран має приблизні заокруглення і круглий отвір камери.

Бібліотека Three.js збережена локально, ліцензія — `vendor/three-LICENSE.txt`.
